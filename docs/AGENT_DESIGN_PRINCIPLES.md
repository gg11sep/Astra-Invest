# Astra Agent Design Principles
**Version 1.1 – November 2026**

## Core Rules
1. Single Responsibility per agent
2. Structured interfaces (prefer typed JSON)
3. Hard Risk Gates are non-negotiable
4. Explicit Autonomy Levels (Research → Advisory → Paper → Live)
5. Complete Logging (Scribe Principle)
6. Challenge by Default (agents should be able to challenge each other)
7. Graceful degradation when data or upstream agents fail

## Current Core Agents
- Regime Agent
- Positioning & Derivatives Agent
- Forensic & Quality Agent
- Scenario & Risk Agent
- Feedback & Learning Agent
- Capital Rotation Agent
- Master Orchestrator
